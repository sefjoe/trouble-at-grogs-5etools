# Trouble at Grog's — 5etools Assets

Hall of Heroes DM qualification one-shot conversion of the older published adventure **Trouble at Grog's**.

- Live 5etools update file: `Trouble_at_Grogs_5etools_CURRENT.json`
- Frozen current snapshot: `Trouble_at_Grogs_5etools_v0.5.json`
- Baseline: **4 level-6 characters**, scalable for levels **4–8** and mixed-level Hall tables
- Runtime target: **3 hours**
- Setting: **Dagger Rock, Faerûn**
- Physical maps: **one simple NCFA-style finale map**

`Trouble_at_Grogs_5etools_CURRENT.json` is the canonical live/update target. Versioned snapshots are recovery points and should not replace the live file during normal updates.

The adventure preserves the original mystery and comedy while using modern redundant clue design, a three-beat investigation structure, fail-forward investigation, and a timed combat finale.

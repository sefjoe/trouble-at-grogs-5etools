# Chaos at the Food Court - Modern Earth

Original adapted one-shot for four level-8 PCs, approximately 3-4 hours. No Mimics.

5etools raw import URL:
https://raw.githubusercontent.com/sefjoe/trouble-at-grogs-5etools/main/one-shots/chaos-at-the-food-court/Chaos_at_the_Food_Court_5etools.json

Current maps are two areas, see the active maps below. Older mall_player.png and mall_dm.png are retained only as legacy assets.

All stat links resolve to built-in Monster Manual 2024 source XMM when it is available in the current 5etools installation. The JSON is a new adventure; existing repo files are unchanged.

These files were structurally created and verified as GitHub assets; live browser import into the user's particular 5etools install is still a separate check.

**Geography:** West and East are two sections of ONE mall building. A 450-foot, 30-foot-wide ordinary shopping concourse with fire doors connects West V12-V16 to East A10-C14. Doors are not magically locked. The food court map remains in place for both its menagerie and the dragon finale.

**Placements:** Hydra WEST L13-N15; EAST Spectator M10, Displacer Beasts N12-O13 / U10-V11, Gelatinous Cube M19-N20 on dining side of kitchen doorway, Bulette Q17-R18, Owlbears G19-H20 / AC19-AD20, Red Dragon Z4-AA5 inside Coronet Jewelers. Eddie begins near AB10. Kitchen shutters explain why Owlbears and Cube do not automatically collide.

**Two clocks:** If PCs are PRESENT for Owlbear combat, Eddie attempts theft on ROUND 1 and the dragon chases in ROUND 2 if he succeeds. If PCs REST or leave East after the menagerie, +5 minutes Eddie approaches, +10 steals, +11 dragon pursues, and +60 minutes he is alive pinned under a kiosk while the dragon guards dropped jewelry in the food court. These are contingent events; PCs can stop them.

**Nine planar anchors:** STOP shuts motor but cannot stop enchanted beam while any linked living creature stays in mall building. Removing a living creature beyond exterior walls, killing it, or moving it off-plane drops its link; rooftop counts as inside. All nine links gone -> cinema return portal opens for one minute with STOP. The projector does not defeat or banish monsters. An intact projector can be cycled to reopen a return window after it expires.

**Validation:** JSON parsed and all four live hosted PNG files passed dimensions and chunk CRC validation. A 13-scenario state-machine dry run passed; encounter XP and footprints were checked. **Live browser import into the user's 5etools and real-character full gameplay have not been verified.**

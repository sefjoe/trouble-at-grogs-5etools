# The Hag's Dinner Party
**System:** D&D 2024 • **Levels:** 2–3 • **Table:** 3–6 players • **Format:** Hall of Heroes one-shot

Rescue Mira from a haunted house where a dead hag's household ritual still demands that its guests prepare for dinner.

# 5etools Import

Import `The_Hags_Dinner_Party_V13_4_5etools.json` as a homebrew adventure. Remove earlier imports of The Hag's Dinner Party to avoid duplicate entries.

The JSON contains four scaled Dinner Golems, a Dinner Specter, and embedded DM, player, and terrain maps. Separate PNG copies are included in this repository.

**Dinner Specters:** Two optional creatures, AC 12, 11 HP each; Spectral Touch +4, 1d6 Necrotic damage. The attack does not reduce maximum HP. They vanish when the golem and both Skeletons are defeated or permanently neutralized.

# The Hag’s Dinner Party — V13.4 (5etools)

Import **The_Hags_Dinner_Party_V13_4_5etools.json** as a homebrew adventure in 5etools, replacing V13.3 to avoid duplicate versions.

## Only change since V13.3
Two optional Dinner Specters retain AC 12 and 11 HP each. Their attack is now **Spectral Touch: +4 to hit, 1d6 necrotic damage**. The attack has **no effect on maximum Hit Points**. Rename from Life Drain deliberately prevents confusion with the published Specter ability. Other traits and behavior remain as in V13.3. Both Specters disperse when the Flesh Golem and the two Skeletons are defeated; never target Mira.

The JSON includes the four custom Golem versions and a custom Dinner Specter monster entry. The unchanged DM, player, and terrain maps are included separately and embedded in the JSON as before. Local JSON parsing and consistency assertions passed; a live import in 5etools is not verified.

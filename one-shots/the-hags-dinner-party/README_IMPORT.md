# 5etools Import

In 5etools, open **Manage Homebrew** → **Load from URL** and paste this direct JSON link:

```text
https://raw.githubusercontent.com/sefjoe/trouble-at-grogs-5etools/main/one-shots/the-hags-dinner-party/The_Hags_Dinner_Party_V13_4_5etools.json
```

The `github.com/.../blob/main/...` page URL is **not** an import URL; 5etools needs the direct `raw.githubusercontent.com` JSON response.

Alternatively, open the [adventure JSON](The_Hags_Dinner_Party_V13_4_5etools.json), download the raw file, and use **Load from File**.

The JSON includes four custom Dinner Golems and a Dinner Specter. Maps are linked to the separate PNG files in this repository using HTTPS URLs.

Dinner Specters: two optional creatures, AC 12, 11 HP each, Spectral Touch +4 dealing 1d6 Necrotic damage, without maximum-HP reduction. They vanish when the golem and both Skeletons are defeated or permanently neutralized.

If an older version has already been imported, remove or update that homebrew entry in 5etools to use the latest copy.

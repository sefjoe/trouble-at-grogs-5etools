# A Minor Noise Complaint

Level 4, five-player, three-hour Hall one-shot. A hag stole the town bell to use as a birdbath; the party is selected as jury. Guilty leads to a bell-recovery fight against Agnes and two bugbears; not guilty leads to a summit defense against Captain Vale and guards.

## 5eTools import

Import this standalone homebrew adventure file by URL:

`https://raw.githubusercontent.com/sefjoe/trouble-at-grogs-5etools/main/one-shots/a-minor-noise-complaint/A_Minor_Noise_Complaint_5etools.json`

The summit tactical map is linked as a 5eTools external image with a raw GitHub PNG URL. It does not require moving images into a local 5eTools installation.

The PDF remains the working design baseline; this JSON reorganizes the same material into sections, with the 2024 monster references, branching finales, and confirmed Arcknight miniatures.
